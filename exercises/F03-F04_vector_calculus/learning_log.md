## 実行前予想

実行前の予想をこの欄に記録していなかったため、以下は実行後に理論と結果を照合して整理した内容である。

- 四公式の成分証明で、積の微分や混合偏微分の交換をどこで使うと予想したか：積の発散には積の微分を使う。curl grad、div curl、curl curlには混合偏微分の交換を使い、その条件としてC²級の滑らかさを確認する。
- 前進・後退・中心差分の誤差は刻み幅を半分にするとどう変わると予想したか：Taylor展開から、前進・後退差分は約1/2、中心差分は約1/4になると考えられる。今回の実行結果もこれと整合した。
- ベクトル解析四公式の残差は格子を細かくするとどう変わると予想したか：外側の微分に中心差分を使うため、格子幅を半分にすると残差は約1/4になると考えられる。今回の粗格子／細格子比も約4となった。

## 証明：curl grad = 0

- 使用した定義：grad φ = (∂xφ, ∂yφ, ∂zφ)。ベクトル B の回転は curl B = (∂yBz − ∂zBy, ∂zBx − ∂xBz, ∂xBy − ∂yBx)。ここで ∂x はxについての偏微分を表す。
- 成分展開：B = grad φ を代入すると、curl grad φ = (∂y∂zφ − ∂z∂yφ, ∂z∂xφ − ∂x∂zφ, ∂x∂yφ − ∂y∂xφ)。
- 混合偏微分を交換した箇所：φがC²級、つまり2階までの偏微分が連続なら、各成分で微分の順序を交換できる。そのため、3成分すべてで同じ値同士の差になり、ゼロになる。
- 結論：curl grad φ = (0, 0, 0)。この証明では混合偏微分の交換を使い、積の微分は使わない。

## 証明：div curl = 0

- 使用した定義：A = (Ax, Ay, Az) とすると、curl A = (∂yAz − ∂zAy, ∂zAx − ∂xAz, ∂xAy − ∂yAx)。ベクトル B の発散は div B = ∂xBx + ∂yBy + ∂zBz。
- 成分展開：div curl A = ∂x∂yAz − ∂x∂zAy + ∂y∂zAx − ∂y∂xAz + ∂z∂xAy − ∂z∂yAx。
- 混合偏微分を交換した箇所：Aの各成分がC²級なら、∂x∂yAz = ∂y∂xAz、∂x∂zAy = ∂z∂xAy、∂y∂zAx = ∂z∂yAxとなる。6つの項が3組に分かれ、それぞれ打ち消し合う。
- 結論：div curl A = 0。この証明では混合偏微分の交換を使い、積の微分は使わない。

## 証明：積の発散

- 使用した定義：div(φ A) = ∂x(φ Ax) + ∂y(φ Ay) + ∂z(φ Az)。
- 積の微分による成分展開：各項に積の微分を使うと、div(φ A) = (∂xφ)Ax + φ∂xAx + (∂yφ)Ay + φ∂yAy + (∂zφ)Az + φ∂zAz。これをまとめると、Ax∂xφ + Ay∂yφ + Az∂zφ + φ(∂xAx + ∂yAy + ∂zAz)となる。
- 必要な滑らかさと、混合偏微分の交換を使わない理由：φとAの各成分がC¹級、つまり1階の偏微分が連続なら十分。使うのは1階微分と積の微分であり、混合偏微分の順序を交換する操作はない。
- 結論：最初の3項は A・grad φ、残りは φ div A なので、div(φ A) = A・grad φ + φ div A。

## 証明：curl curl

- ベクトルLaplacianの定義：∇²A = (∇²Ax, ∇²Ay, ∇²Az)。例えば、∇²Ax = ∂x²Ax + ∂y²Ax + ∂z²Ax。
- 三成分の展開：回転の定義を2回使うと、次のようになる。

x成分：∂y∂xAy + ∂z∂xAz − ∂y²Ax − ∂z²Ax。微分の順序を交換し、∂x²Axを足して引くと、∂x(div A) − ∇²Axとなる。

y成分：∂z∂yAz + ∂x∂yAx − ∂z²Ay − ∂x²Ay。微分の順序を交換し、∂y²Ayを足して引くと、∂y(div A) − ∇²Ayとなる。

z成分：∂x∂zAx + ∂y∂zAy − ∂x²Az − ∂y²Az。微分の順序を交換し、∂z²Azを足して引くと、∂z(div A) − ∇²Azとなる。
- 混合偏微分を交換した箇所と条件：各成分の混合偏微分を、外側の微分がそれぞれx、y、zになるよう交換した。Aの各成分がC²級なら、この交換ができる。積の微分は使わない。
- 結論：三成分をまとめると、curl curl A = grad div A − ∇²A。

## 前進・後退・中心差分

- 3つの差分式：前進差分は (f(x+h) − f(x))/h、後退差分は (f(x) − f(x−h))/h、中心差分は (f(x+h) − f(x−h))/(2h)。
- 参照する近傍点の違い：前進差分はxとx+h、後退差分はx−hとx、中心差分はx−hとx+hを使う。
- Taylor 展開から予想する収束次数：十分滑らかな関数では、前進差分の誤差の主要項は h f''(x)/2、後退差分は −h f''(x)/2、中心差分は h² f'''(x)/6。したがって前進・後退差分は一次、中心差分は二次の収束を予想する。主要項がゼロでなく丸め誤差が支配しない範囲では、hを半分にすると誤差はそれぞれ約1/2、約1/4になる。

## 一次元の誤差と収束次数

標準条件は `f(x) = sin(x) * exp(x)`、`f'(x) = exp(x) * (sin(x) + cos(x))`、評価点 `x = 0.4` とした。

## 解析的証明と数値的検証の役割

- 解析的な証明がすべての十分滑らかな場について保証すること：必要な滑らかさを満たす一般のφとAについて、四公式が成り立つことを示す。混合偏微分を交換する証明ではC²級、積の発散ではC¹級を条件とした。
- 有限個の格子で得た数値結果が示すことと、単独では保証しないこと：今回の関数と評価点では、格子を細かくすると残差が減り、中心差分の二次収束と整合した。有限個の数値結果だけでは、すべての関数・評価点で公式が成り立つことや、実装に誤りがないことまでは保証できない。
- 積の発散の左右辺と、ほかの公式の内側・外側で、解析微分と数値微分をどう使い分けたか：積の発散は、左辺の積を数値微分し、右辺には提供済みの解析微分を使った。curl gradとdiv curlは、内側のgrad・curlに提供済みの解析微分を使い、外側を自分の中心差分で計算した。curl curlも内側のcurlを解析微分、外側を数値微分とし、右辺のgrad div A − ∇²Aは解析微分で評価した。
